title: Location Map
description: "An embedded Google Maps location, optionally introduced by a heading."
overview: "Use Location Map to embed a business address as a live map -- e.g. on a Contact page -- instead of a static image or a raw iframe glued into a generic section. Takes a plain address string (geocoded by Google Maps at render time, no API key required) plus height/zoom/rounded display options. Built 2026-07-27 to give WordPress-to-Astro conversions a real, typed, reusable target for Elementor `google_maps` widgets, which previously only had a raw-iframe fallback with no first-class component."
